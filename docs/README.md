# Valis documentation

## Start here

- [Install](install.md): the pack, the node packs and the models each feature needs, and how to check it works.
- [Your first film](first-film.md): from one line to a scored, cut short film in the Film tab, then scoring it again.
- [Troubleshooting](troubleshooting.md): missing nodes and models, memory, light drift, effects that don't fire.

## The tabs

| Guide | What it covers |
|---|---|
| [Film](guides/film.md) | One line or a script to a cut film: the plan, building from references, the steps, the shot cards. |
| [Create](guides/create.md) | Cinema Studio: the director's panel, palettes, trained camera moves, Frame it, Shoot it, Extend, Upscale, Relight. |
| [Edit](guides/edit.md) | Name it and change it: Find it, Transform (57 looks or your own), Remove, Swap, Turn. |
| [Genjutsu](guides/genjutsu.md) | Keep a performance, change the cast, the place or the look: motion transfer, restyle, object swap, check source. |
| [Score](guides/score.md) | A song as lanes: make a score, map lanes to effects, lay clips on the shots, preview live, render and cut on the bars. |
| [FX](guides/fx.md) | The library of 24 effects as layers on a clip, each firing on a lane, each with its own sound. |
| [Extras](guides/extras.md) | Stereograms and kinetograms, loops, and Stage (experimental). |
| [Renders](guides/renders.md) | The queue, the bin, the machine, Setup, the engine switch and the end-to-end test. |
